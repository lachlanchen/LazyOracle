# Native LazyOracle: study and reflection

The owner requested meaningful native features after the App Store rejection.
Read-only App Store Connect verification on September 29 confirms that iOS
1.0.0 build 12 was rejected under 4.3(b), reviewed September 28 on iPad Air
11-inch (M3). That is the classic build, not the current native TestFlight 18.
Private review evidence is in `.runtime/2026-09-29-distinctive/`.

The new native experience leads with two connected offline workflows:

- **Change Atlas:** choose any of the 64 hexagrams, change individual lines,
  inspect both trigrams and the resulting figure, and explore nuclear, opposite
  and inverse transformations. A visible construction explains which lines
  changed. This is deliberate study, with no random cast or model dependency.
- **Reading notebook:** deliberately save an immutable computed result, record
  a personal reflection and a small action, then return to record an observation.
  Original facts remain separate from notes and model narration. Export is an
  explicit user action; no account, automatic upload or cross-app migration.

Keep existing practices and live native cameras. Native SwiftUI (including Mac)
and Compose share the same tested Atlas/summary rules. Preserve current practice
state, histories and all existing store identities. The classic Auspice release
is not replaced or submitted as another copy of this native study experience.

Validation must cover all 64 figures and changing-line combinations, round-trip
notebook storage, duplicate saves, relaunch/edits, empty state, navigation and
offline use. Native builds and UI evidence are required. New release metadata
must accurately show the native candidate and describe a reproducible review
walkthrough. Prepare review materials only after implementation; a meaningful
change does not guarantee approval. No review reply or resubmission has been
sent by the investigation.
